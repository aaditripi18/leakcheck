# Clean benchmark splits

Generated by `scripts/splits_index.py` from `splits/*.json`. Do not edit by hand.

For each benchmark: which test rows have an exact or near copy in the training set. Drop them and the test set no longer overlaps training; the training set is left as published. Each list was produced by `leakcheck clean` (conflicts kept, so training rows do not change) and re-checked on every row of the cleaned split (`recheck` in the JSON).

**Use it without leakcheck.** `<case>.drop_source.txt.gz` lists the dropped rows by position in the original data, numbered as the JSON's `source_numbering` says. For a random split, `<case>.test_source.txt.gz` lists the test rows and `split_rule` gives the scikit-learn call that rebuilds them. Download the lists from the [`clean-splits` release](https://github.com/aaditripi18/leakcheck/releases/tag/clean-splits); `index.json` has each file's SHA-256.

**Or rebuild the files:** `python -m experiments.clean_splits write <case> --out DIR` writes `train.csv` and the cleaned `test.csv` from the pinned data.
